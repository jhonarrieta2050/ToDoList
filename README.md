# ToDoList API

API REST para gestionar tareas con Spring Boot.

## Base de datos (Docker)
```bash
docker compose up -d
```

## Endpoints
- GET `/tareas`
- GET `/tareas/{id}`
- POST `/tareas`
- PUT `/tareas/{id}`
- DELETE `/tareas/{id}`

## Documentación
Swagger UI: `/swagger-ui/index.html`

## Postman
La colección de ejemplo está en `postman/todolist.postman_collection.json`.
